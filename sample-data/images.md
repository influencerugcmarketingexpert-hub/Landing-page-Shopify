# Demo imagery

Each URL resolves to a real, publicly available image. This file documents every URL referenced by the CSV, together with the photographer credit and a link back to the source on Unsplash.

Unsplash photography is licensed under the [Unsplash License](https://unsplash.com/license), which permits commercial use without attribution. Crediting the photographer is still strongly encouraged, and Orlaven does so for every demo image below.

> **Important:** These images are demo placeholders. Before launching a live store, every demo photo should be replaced with real Orlaven product photography. See "Recommended alternative sources" at the bottom of this document.

## Images referenced by theme settings

The theme editor exposes image picker settings for:

- Global logo (`settings.logo`)
- Favicon (`settings.favicon`)
- Social sharing image (`settings.social_sharing_image`)
- Password page background (`settings.password_background_image`)
- Hero slides (`hero` section: per-slide `image_desktop`, `image_mobile`)
- Custom banner (`custom-banner` section)
- Lookbook tiles (`lookbook` section, per block)
- Shop by category / style tiles (per block)
- Brand story poster (`brand-story` section)
- Materials guide illustrations (`material-guide` section, per block)
- Newsletter background (`newsletter` section)
- Mega menu promo tiles (`header` section, per block)
- Press logos (`press-strip` section)
- Reviews/UGC media (`reviews-ugc` section)
- Contact form background (`contact-form` section)
- Size guide illustrations (`size-guide` section)
- 404 popular collection fallback media

None of these have defaults pointing at external URLs. On a clean install every image slot is empty and renders a neutral placeholder SVG via `snippets/responsive-image.liquid`. Merchants upload their own imagery via Shopify Admin -> **Online Store -> Themes -> Customize -> Theme settings** (global) or per-section pickers.

## Replacing demo imagery before launch

1. Generate final product photography (lifestyle + cutout) at a minimum of 1600 px on the long edge.
2. In Shopify Admin, open each demo product created by the CSV import.
3. Delete the Unsplash-hosted images from the product's **Media** section.
4. Upload your replacement images in the intended order (image 1 becomes the card thumbnail).
5. For theme-level imagery (logo, hero, lookbook, etc.), re-open the theme editor and replace each image picker's value with an asset uploaded to **Content -> Files**.

## Recommended alternative sources

If you need to keep using stock imagery temporarily:

- [Unsplash](https://unsplash.com) - search terms: "leather jacket", "atelier", "craftsman", "motorcycle jacket"
- [Pexels](https://www.pexels.com) - similar license to Unsplash
- [Burst by Shopify](https://burst.shopify.com) - royalty-free, curated for commerce
- [Pixabay](https://pixabay.com) - broader catalogue, verify license per image

For production photography we strongly recommend:

- Commissioning a small lifestyle shoot (one model, two-three outfits per jacket, consistent lighting).
- Shooting a cutout pack on a neutral seamless for PDP hero images.
- Capturing two or three macro shots of stitching, hardware, and lining to sell craftsmanship.
